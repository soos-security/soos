## 3. Test contract: `tests/invariants/src/readme_contract.rs` (rows RDM1–RDM8, RDM10–RDM13)

Registered in `tests/invariants/src/lib.rs` as `#[cfg(all(test, unix))] mod readme_contract;`.
std only, no new dependency. Helpers (pure, unit-tested on synthetic Markdown):

- `strip_fences(md) -> String`: drops fenced blocks (```` ``` ```` and `~~~`) and their fence lines.
- `strip_inline_code(line) -> String`: drops `` `...` `` spans.
- `link_targets(md) -> Vec<String>`: every Markdown `](target)` (links and images, nested badge
  form included), reference definitions `[label]: target`, and HTML `href=` / `src=` /
  `srcset=` values, outside fenced and inline code. The target is the first whitespace-separated
  token, `<>` trimmed.
- `check_relative_target(target, root) -> Result<(), String>`: external (`scheme:` or `//`) and
  pure `#anchor` targets are skipped; `?query` and `#anchor` are removed; an absolute path or
  an empty path is refused; the path must exist (file or directory).
- `badges(md) -> Vec<String>`: image URLs on `img.shields.io` or this repository's workflow
  `badge.svg`.
- `is_release_badge(url)`: lowercase URL containing `release` or `/v/tag` or `/tag/`.
- `contains_whole_word(text, word)`: ASCII case-insensitive, boundaries are non-alphanumeric.
- `level2_headings(md) -> Vec<(usize, String)>` outside fences; `section(md, keyword)`.
