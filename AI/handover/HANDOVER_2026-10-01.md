Highlights:

- **Daemon**: request nonces are logged only as an 8-hex-digit SHA-256 digest; every response
  carries real `issued`/`expires` stamps (clock failure → no Allow); graceful shutdown drains
  connections within one `connection_timeout`; the panic hook logs through `tracing` without the
  panic message; `Type=notify` readiness after the socket is bound; `StatusResponse::memory_locked`
  reports `mlockall` swap protection; `DaemonConfig::default()` uses the single warmup default (0).
- **PAM**: the panic hook is installed once and chained (never left dangling); `PamHooks` is the
  production path; rejected module arguments are logged as warnings without their values; the module
  **sends no message at all when the daemon is unreachable** (still `PAM_IGNORE`).
- **Anti-spoofing**: opt-in encrypted evidence of spoof attempts; a detected spoof is never reported
  as `NoFace`.
- **Storage**: AES-GCM associated data binds uid, file role and format version; legacy files remain
  readable and are re-encrypted on the next write.
- **Install**: `scripts/install_rustup.sh` downloads a pinned `rustup-init`, checks its SHA-256
  (digests stored in the script) and installs Rust 1.98.1; systemd start guards verified.
- **Vision**: embedding input layout / 512-D output validated fail-closed; `size_bytes` per model in
  the manifest bounds downloads; manifest-gated wiring for a second PAD model (disabled).
- **Camera**: `soos-admin camera list|probe` shares the daemon's resolver and explains the selection.
- **CI / Docker**: package and distro harnesses always rebuild release artifacts; review-report
  hygiene.
- **Models**: ArcFace licence recorded as SPDX `NOASSERTION` (the source repository declares none).
