### Advisory (not blocking)

- A1 `write_atomically` does not `fsync` the parent directory after `rename`. After a crash the file is old or new, never torn, so this is acceptable. A directory fsync would make the change durable.
- A2 `systemctl --user try-restart` / `enable|disable --now` under the 3 s deadline: killing the client does not cancel the job, so the "did not answer within 3000 ms" error can show while the restart completes anyway. The wording is acceptable. The argument vectors are fixed by contract, so `--no-block` is out of scope here.
- A3 `pkexec /usr/bin/touch` / `/usr/bin/rm` use the generic `org.freedesktop.policykit.exec` action, so the Polkit dialog shows the raw command. This is acceptable for AS-2; the dedicated `soos-admin` subcommand noted in the spec would give a clearer prompt.
- A4 Test strength. A wrong implementation could still pass the contract on these points, covered here by review or additive tests: the cross-runner exclusion (constraint 6), root-HOME persistence (constraint 2), dead-worker reporting (constraint 3), and the real `SystemProgramRunner` deadline kill and reap (exercised only through fakes). An additive test running `/usr/bin/sleep 5` under a 100 ms deadline would cover the last one cheaply.
